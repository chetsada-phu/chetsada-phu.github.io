Can machine learning and macroeconomic context improve on using today’s exchange rate as the next prediction?

USD/THB · Model comparison · Rolling evaluation

USD/THB forecasting

I compared seven approaches to predict the next observed USD/THB exchange rate, testing both exchange-rate history alone and additional economic indicators.

Two experiments

Univariate: exchange-rate history only.
Multivariate: exchange-rate history plus interest-rate and inflation differentials, Brent oil prices, and VIX. Random Walk and the pretrained models remain univariate references.

Seven models, different assumptions

  • Random Walk: the next rate equals the latest observed rate; the baseline to beat.
  • XGBoost: gradient-boosted trees for nonlinear relationships in the input features.
  • RNN: a recurrent network for learning patterns across sequential observations.
  • LSTM: a gated recurrent network designed to retain and forget information over time.
  • Transformer: an attention-based sequence model.
  • Chronos Bolt: a pretrained time-series model used without fine-tuning.
  • TimesFM: a second pretrained time-series model used without fine-tuning.

Select on validation. Evaluate on test.

Used 689 observations from January 2024 to September 2026, with 501-observation rolling training windows, 103 validation targets, and 85 test targets. Scalers were fitted inside each window; XGBoost and neural models were refitted at each forecast origin.

RNN was selected using validation RMSE.Hyperparameters and model choice were fixed before test evaluation; test rankings were not used to select a replacement.

Validation results, implementation, and limitations

Validation RMSE: univariate RNN 0.180181 versus Random Walk 0.181736; multivariate RNN 0.178708 versus Random Walk 0.181736. Settings were chosen on aggregate validation RMSE. Earlier actual observations could enter later rolling windows once observed.

Implementation: separate univariate and multivariate notebooks, window-local scaling, rolling refits, and pinned pretrained checkpoints. Figures are retained notebook results, not a fresh full rerun of the public copies.

Limitations: the test period was revised after earlier 2026 results had been inspected, so it is not an untouched final holdout. Macro publication timing and foundation-model pretraining overlap are unverified. Small differences do not establish statistical significance or trading profitability.
